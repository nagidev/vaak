## Features
### 🔀 Non-linear Dialogue
Create non-linear narratives by linking dialogues easily.

### 🖥️ JSON export
Export dialogue files in easy to read JSON format.

### ▶️ Built-in simulator
Test dialogues using the built-in simulator with the click of a button.

### 📱 Mobile support
Responsive application design allows it to be used comfortably on a mobile device.
